# EVE 助手设计讨论

## 已确认

- 首版聚焦 Gas Huffing 与 Arbitrage Hauling。
- 用户先选择活动模式，系统自动读取角色上下文并生成方案。
- Hauling 首版提供高安、低安、00 独立开关，可组合、持久保存；不预设玩家偏爱高安。
- 尽量通过 API 获取数据并计算，避免要求用户填写具体数字。
- Gas 支持收藏当前星系，自动记录位置；收藏时可选择见过的 Gas 类型，并影响后续路线规划。
- Hauling 根据玩家技能推荐船与拟合。
- 两种活动均提供技能与进阶路线。
- 成长建议分为效率升级和能力解锁；效率升级报告增量投入、增量收益与回本条件，能力解锁说明新增场景。
- Hauling 首版仅按现有订单生成立即买入、运输、立即出售的方案；抵达前订单可能改变，不承诺锁定利润。
- Gas 收藏是路线偏好，不是必经点；风险或绕行成本过高时可跳过，并向用户解释。
- 默认保守风险模式，可切换均衡或激进；系统据此限制单趟投入与货值，显示实际预算上限，无需用户填写数字。各模式具体规则待定义。
- 升级报告先给同条件理论增益与回本条件；个人历史充分后补充个人化估算，区分采速提升与整趟实际收益。
- Hauling 必须展示船装升级，并覆盖没有运输船的新手：根据角色技能推荐入门船装、购置与周转资金，并关联购置后可承接的货单。不能只提供已有运输船才可使用的流程。
- Gas 使用短途、标准、长途三档，默认标准；显示预计旅行时间，扫描和采集耗时单独标为不确定，提供返回出发地选项。
- Hauling 新手可获高安练习建议，但不覆盖玩家主动选择的区域；区域选择与风险档位独立。
- 船装推荐使用审核模板，按角色技能、预算和市场供应适配装备，并校验属性；首版不做全部装备组合的自动搜索。
- Gas 同样覆盖从零入门：自动列出必要技能、船装、缺件与总投入，再生成首次搜索路线；已有基础时直接进入活动推荐。
- Hauling 首版交易地点限所选高安/低安/00 区域内的 NPC 空间站；玩家结构留待后续扩展。所选区域约束完整路线。
- Gas 首版仅覆盖高安和低安；00 和虫洞空间留待后续。
- 首版只考虑一个角色，不做多角色添加、切换或联合规划。
- UI 保留 EVE 视觉风格：深色半透明面板、冷色细线、紧凑信息布局与克制状态色，同时保障中文、数字、焦点和控件可读性；完整视觉约束见最终产品设计。

## 讨论状态

产品范围、主要交互与验收边界已由用户确认，规格已发布为 ready-for-agent。开源工具与 Reddit 跑商调查已纳入[最终产品设计](../../docs/design.md)；第 3 版按用户纠正增加 Hauling 高安/低安/00 独立开关，替代先前不覆盖 00 的决定。尚未拆票或实现。

## 研究补充的设计约束

- 默认同一采购站/出售站组合货单，避免为凑满货舱随意绕路；记录完整采购前移动和可选回程。
- 机会时效、购买前复核、买单失效后的缩量/余货/替代即时买家成为显式流程。
- 船装模板随 SDE 变更失效重审，不直接套用旧 Sunesis 等攻略。
- 历史快照机会存续仅作研究，不冒充实际成交或个人收益回测。
- 证据：[开源工具](../../docs/research/hauling-open-source-tools.md)、[Reddit 经验](../../docs/research/hauling-reddit-experience.md)。

## 规格阶段需明确的验收规则

- 保守、均衡、激进模式对应的资金/货值限制与风险规则；钱包余额不等于风险预算。
- 短途、标准、长途的路线搜索范围和预计时间假设。
- 审核拟合模板来源与验证方法；API 缓存或字段缺失时的降级行为。
- 新手买船投入、货物周转资金与升级增量回本分别计算；没有可信收益分母时不给伪精确回本时间。
- 数据采集遵守授权、缓存和限流；不读取无关私人数据。纯 API 无法观察的信息保留未知。

## API 核查结果

- 当前公开规格已生成角色 GET 端点清单；真实角色授权与返回数据尚未集成验证。
- 当前船实例可关联资产树重建装备和货物快照，但资产有缓存，保存拟合不等于实际装配。
- 技能有训练等级和生效等级；新训练路线和拟合性能需要计算，并显式说明假设。
- Gas 采集账本可形成日期、星系、类型、数量证据，不能确认实时气矿或精确采集时长。
- 收藏保存在本应用，不依赖已移除的 ESI 书签接口。
- 详细依据：[角色 API 边界](../../docs/research/character-api-boundaries.md) 与 [端点清单](../../docs/research/character-api-inventory.md)。

研究依据见 `docs/research/`；已有研究中的 API 局限与推算标记仍适用。
