# 缓存与网络请求速度

Status: ready-for-agent
State: implemented

## Request

增加 cache，优化网络请求速度。

## Findings

上游已使用 HTTP 缓存，但页面每 4 秒仍完整拉取约 13 MB 的本地行情 JSON，产生重复传输、反序列化和报价重算。相同航程也缺少派生结果缓存；定时器会与未完成的轮询重叠。

## Changes

行情和角色 HTTP ETag/304、gzip 与复用序列化；行情快照版本＋增量进度；页面内存条件请求缓存与并发合并；串行、自适应前后台轮询；独立读取并行；航程 30 秒/256 项内存缓存，按角色/位置/船型/技能/策略隔离，失败不缓存，断开清空。保留金融数据有效期和失效重算。

## Verification

29 个单元/服务测试及 7 个浏览器测试通过。新增并发合并、304 对象复用、压缩、只传增量、过期、容量上限、失败重试与航程缓存命中验证。构建通过。

本机实测首次网络响应约 13.17 MB → 1.35 MB；未变重复响应为 304/0 字节（约 3ms，原约 55ms）；进度增量约 167 字节。报告在忽略的 artifacts/cache-before.json 和 cache-after.json。

真实浏览器轮询验证：首次压缩响应约 1.35 MB，后续仅收到 167 字节的快照进度增量，页面错误 0。真实页面继续显示真实数据模式。正式服务已加载本次改动并保持运行。
