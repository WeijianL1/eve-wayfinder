# 当前船运力、技能、航程与 ISK/h

Status: ready-for-agent
State: implemented

## Request

读取用户货船舱位和技能，推算运输时间与 ISK/h，尽量自动化。

## Outcome

- 自动读取已授权角色当前船、技能、资产，当前 Iteron Mark V / Gallente Hauler III 的已验证容量为 6,670 m³。
- 真实资产没有当前船及子资产，保留实际占用/空余未知，使用显式空舱条件场景。
- 单船限量在订单深度匹配阶段执行，保留最小成交量约束；市场船体按包装体积。
- 前 20 个装载后候选自动估算，采用真实星门/站点坐标、完整采购/出售/返程路线，拒绝未允许区域；可按 ISK/h 低端排序。
- 航程是手动跃迁场景，船体+技能起跳，装配性能、操作耗时、拥堵和损失不假装是实测数据。尚非全船型 Dogma 引擎。

## Verification

21 个单元/服务测试通过，新增私有路线坐标/禁行段服务测试单独通过（总计 22）；2 个浏览器测试与构建通过。实际角色 smoke 成功，真实浏览器页面 20 行均有估算且无 JS 错误；高安+低安场景截图 artifacts/hauling-personal-isk-hour.png。私有账户数据不进入 Git。
