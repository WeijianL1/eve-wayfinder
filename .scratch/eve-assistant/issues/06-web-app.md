# 从 Electron 改为网页应用

Status: ready-for-agent
State: implemented

## Request

用户决定不再使用 Electron，重构为网页 app。

## Outcome

- React 前端通过同源 HTTP API 使用独立 Node 服务；npm start 构建并启动 127.0.0.1:5173，npm run serve 直接运行已构建版本。
- 开发模式使用 Vite 热更新，直接挂载相同 API 和持久化凭据，不再桥接 8767。
- 删除 Electron 依赖、入口、启动与 smoke 脚本；保留 EVE 视觉和现有活动功能。
- 授权改为服务端 AES-256-GCM 文件存储，密钥/文件限制本地读写；token 不进浏览器或公共缓存。SSO 点击时先开浏览器标签页，再转到官方登录。
- 已一次性迁移本项目既有授权与公开缓存，原桌面加密文件保留，不触碰 eve-trader 的私人授权。浏览器 origin 保持相同，因此已有 localStorage 偏好可保留。
- 当前是本机单用户网页服务，公网多用户登录与租户数据隔离不属于本次迁移。

## Verification

- 构建与正式启动通过；当前服务已恢复角色授权、Client ID 和 629 商品公开缓存。
- 26 个单元/服务测试通过，含凭据重启恢复/加密完整性/静态文件与同源 API。
- 7 个浏览器测试全部通过，覆盖真实与演示流程、个人 ISK/h、顺路单以及浏览器 SSO 标签页。
- 独立开发端口验证页面与 API 都返回成功，读取相同授权；验证完已关闭开发实例。

迁移后的真实私有 API 实测返回 200，当前船、实际技能及容量模型均可读取；无需重新登录。凭据、密钥与迁移的公共缓存均确认被 Git 忽略。

网页服务真实公开源 smoke 通过：629/629 商品、44,574 条订单、377 个 NPC 站、1,887 个完整且当时新鲜的来源，失败 0；路线与 zKillboard 验证成功。正式网页服务保持在 127.0.0.1:5173 运行。
