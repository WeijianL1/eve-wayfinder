# 原型交付与验证

日期：2026-10-18。原型分支：`prototype/eve-master`。用户问题：能否用保留 EVE 风格的 UI，免填数字走通单角色 Gas 与 Hauling 信息流程？

这是 0.1 合成演示的历史验证记录。0.2 真实数据接入见 [live-data.md](live-data.md)，本文件的“未接入”限制仅指该轮交付。

## 实际结果

- 本机 macOS / Node 24.19 / Electron 44.9 / React 19.3 / Vite 8.3。
- `npm test`：7 项全部通过。覆盖八种区域组合、全路径约束、跨商品共享资金/舱位/订单量、无船入门、过期/撤销阻塞、进阶 00 合成路线、收藏排序和非正增益不算回本。
- `npm run build`：TypeScript 与离线前端构建成功。
- `npm run test:ui`：3 项全部通过。覆盖 Gas 收藏及重载持久化；区域与风险独立；采购装载→买单失效→替代报价→前往→出售→返程；活动日志；无船和进阶 00；报价过期恢复；600/960px 无横向溢出；紧凑导航；Escape 关闭弹窗；重置；没有数值输入表单。主流程未收集到页面异常。
- `npm run test:electron`：原生 Electron 从本地构建加载，Gas/Hauling/数据边界弹窗正常；确认 sandbox 与 contextIsolation 开启、nodeIntegration 关闭。无需 Vite server。
- 人工查看了浏览器 Gas 和 Hauling 截图，页面结构、表格与 EVE 风格均可见。截图位于本地忽略目录 artifacts；截图不是生产 UI 的用户验收。

构建会显示 lucide-react 的 `use client` 指令在纯客户端 bundle 中可能不保留的警告；本原型无服务器组件，构建和实际运行通过。该提示未伪装成失败或证明生产兼容性。

## 可运行交互

Gas：地图查看与高/低安模拟移动、距离/风险/返程、收藏当前星系、多气体可选反馈、取消收藏、选择搜索方案、成长入口。

Hauling：三个区域独立开关、船型筛选、风险档位、采购清单、船装/商品本金分列、选择方案、模拟采购/飞行/买单撤销/替代报价/出售/返程。没有实时安全或盈利承诺。

Growth / Records / Settings：入门与升级卡片、条件回本、示例技能路线、装配预览、日志导出、五种场景、显示选项、数据边界和本地重置。

## 已知边界

1. 只有合成数据；没有真实角色授权、ESI 市场/账本、zKillboard、SDE 或 Dogma。未读取相邻项目的账号授权文件。
2. 所有船装及技能只是示例，示例税率固定 5%；不能当作实际游戏拟合、有效训练时间或收益结论。
3. 每件合成商品只有一个价格层，不代表生产规格的真实多层订单簿执行已完成；组合装载使用确定性贪心策略，不宣称全局最优。
4. 所谓 00 门槛是演示场景规则，不是实际 00 安全验证。替代报价的 12% 折价也是情景参数，不是市场推断。
5. 运行记录、货物和收入都是模拟事件；钱包基础快照固定，不冒充真实余额更新。退出计划仍有货时记录为未实现，不记录假出售。
6. 当前窗口位置和 UI 演示状态不等于游戏状态，不控制鼠标、键盘或 EVE 客户端。
7. 原型机械可运行性已验证，用户对布局/流程的评价仍待体验；不得把本轮结果标成整个生产规格已实现。
